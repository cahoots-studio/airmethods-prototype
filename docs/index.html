Structure is independent of size

Known issues

Figma schemes don’t cascade to nested components. A section set to Scheme 2 does not propagate that scheme to component instances nested inside it — Figma’s variable mode scoping stops at the first component boundary. The CSS cascade works correctly; this is a Figma-only limitation.
